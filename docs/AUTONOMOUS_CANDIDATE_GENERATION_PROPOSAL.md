# 自主候選生成規格提案（待使用者核准，未啟用）

狀態：**PROPOSAL_ONLY / NOT AUTHORIZED**。此文件不授權更改模型、Features、風控、資料庫、排程或啟動自主參數生成。

## 目的
將合格交易證據轉成可重現的雙模型候選實驗，取代只輪流測試固定十組參數的假自主學習。四策略各自研究，方向層與價格結構層分開調整。既有 HistGradientBoosting、原生 K 線與 Features 不變。

## 候選生成方案（以下數值全部待核准）
- 每輪只調整**一個模型層**與**一個超參數**，其餘固定；同輪保留未修改的基準組。
- 方向層：候選參數僅 `max_iter`、`learning_rate`；建議探索集合分別為 `[60, 80, 100, 120, 160, 200]` 與 `[0.025, 0.05, 0.10]`。此為待核准方案，不是既有授權。
- 價格結構層：同樣兩個超參數與待核准探索集合，但與方向層獨立紀錄及選擇，不共享最佳參數。
- 暫不自動新增／刪除 Features、不變更交易信心門檻、進出場規則、RR、持倉額度或風控。
- 候選選擇：依研究期符合資格的交易證據提出假設；一次測試一個可歸因變更，記錄來源試驗、假設、模型層、參數前後值、資料指紋、研究期間、費率與滑價。
- **無合格回饋**：停止回饋驅動候選生成，標記 `NO_ELIGIBLE_FEEDBACK`；是否啟用額外無監督探索須另案核准，不使用回撤 >40% 試驗做失敗學習。
- **回撤 >35–40%**：僅失敗診斷；**>40%**：審計留存，不做候選生成或失敗學習。
- 實驗預算建議：每策略每批最多 10 個新候選；100 輪需另外明確授權計算成本、持久化、重啟與停止條件。此上限目前尚未核准。

## 比較與驗證
1. 比較前須確認相同策略、標的、研究窗口、來源資料指紋、費率、滑價與資金／風控配置；任何缺項均拒絕宣稱改善。
2. 研究期結果只可用於挑選**待驗證候選**，不能自動升級。至少五筆正常完成交易；回撤資格按已核准風控分級，0–8% 同級，8–35% 可研究，35–40% 僅診斷，>40% 排除。
3. 保留未參與選模的獨立驗證窗口；不得以 holdout 結果反覆調整候選。未驗證、樣本不足、交易異常或資料不一致時拒絕升級。
4. 保留年化報酬率、勝率、平均交易評分、最大回撤、交易數、手續費、滑價與逐輪改善／退步原因。
5. 目標年化 >=10%、勝率 >=70%、平均交易評分 >=65 且符合既有風控與獨立驗證；不保證達成。
