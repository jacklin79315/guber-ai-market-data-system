# P1 雙角色權限設計與落地狀態

## 權限
- admin：可以查看所有研究資訊，也可管理訓練、專家、模型、使用者及系統設定。
- viewer：僅能讀取市場、資料品質、AI 訊號、訓練報告、模型結果及通知；不能修改研究或系統設定。
- 未知角色、未知權限一律拒絕。未規劃任何真實下單權限。

## 已實作
- frontend/access-policy.mjs 定義角色與權限矩陣。
- frontend/access-policy.test.mjs 驗證一般帳號唯讀、管理員權限及拒絕未知角色。
- /api/auth/user 對已核實的管理員回傳最小化角色與權限資料，避免把原始使用者資料當成授權依據。
